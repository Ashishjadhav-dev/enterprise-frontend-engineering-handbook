# Appendix 15: Table Component Checklist

Reusable reference for project delivery, reviews and engineering governance.

- Semantic headers and caption
- Accessible sort state
- Deliberate widths
- Sticky header behaviour
- Truncation tooltips
- Pagination or virtualization
- Responsive alternative
- Loading, empty and error states

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
