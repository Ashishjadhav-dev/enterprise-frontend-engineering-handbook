# Appendix 11: Incident Response Guide

Reusable reference for project delivery, reviews and engineering governance.

- Confirm impact and affected routes
- Identify release and correlation IDs
- Disable risky feature through kill switch
- Rollback when recovery is faster than diagnosis
- Preserve logs and evidence
- Communicate status
- Create root-cause analysis
- Add regression protection

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
