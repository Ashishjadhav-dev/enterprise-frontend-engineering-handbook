# Appendix 24: Observability Event Standard

Reusable reference for project delivery, reviews and engineering governance.

- Event name and business meaning
- Trigger condition
- Required properties
- Sensitive fields excluded
- Sampling policy
- Owner and dashboard
- Retention expectation
- Versioning and deprecation

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
