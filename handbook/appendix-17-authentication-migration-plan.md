# Appendix 17: Authentication Migration Plan

Reusable reference for project delivery, reviews and engineering governance.

- Inventory existing token storage
- Define server session contract
- Introduce cookie-based session
- Add centralized unauthorized handling
- Migrate protected routes
- Migrate permissions
- Remove legacy storage
- Monitor and roll back safely

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
