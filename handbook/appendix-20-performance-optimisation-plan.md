# Appendix 20: Performance Optimisation Plan

Reusable reference for project delivery, reviews and engineering governance.

- Capture route baseline
- Rank largest bundles
- Remove artificial delays
- Lazy-load heavy tools
- Move data work server-side
- Optimise images and fonts
- Virtualize dense interfaces
- Enforce budgets in CI

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
