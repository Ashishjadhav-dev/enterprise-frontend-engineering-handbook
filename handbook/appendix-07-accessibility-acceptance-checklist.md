# Appendix 7: Accessibility Acceptance Checklist

Reusable reference for project delivery, reviews and engineering governance.

- Keyboard-only completion
- Visible focus
- Correct accessible names
- Labels and errors associated
- Modal focus trapped and restored
- Contrast meets target
- Zoom and reflow supported
- Reduced motion respected

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
