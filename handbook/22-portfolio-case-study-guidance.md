# 22. Portfolio Case Study Guidance

Present architectural work credibly and without exposing proprietary information.

## Positioning

- Describe the handbook as a vendor-neutral engineering blueprint informed by practical experience.
- Focus on decisions, trade-offs, principles, and reusable examples rather than claiming ownership of confidential systems.
- Link the portfolio case study to the GitHub chapters and downloadable PDF.

## Public disclaimer

This handbook is an independent engineering reference created for educational and portfolio purposes. It does not disclose proprietary source code, confidential company information, customer data, credentials, or organisation-specific implementation details.
