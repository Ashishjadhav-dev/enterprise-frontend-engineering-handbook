# Appendix 8: Performance Review Checklist

Reusable reference for project delivery, reviews and engineering governance.

- Route JavaScript measured
- Heavy dependencies lazy-loaded
- Server rendering considered
- Images and fonts optimized
- Long lists virtualized
- Duplicate requests removed
- Searches debounced and cancelled
- Web Vitals observed

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
