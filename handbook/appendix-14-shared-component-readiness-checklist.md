# Appendix 14: Shared Component Readiness Checklist

Reusable reference for project delivery, reviews and engineering governance.

- Clear responsibility
- Typed API
- All visual and interaction states
- Keyboard and screen reader support
- Responsive behaviour
- Theme support
- Unit or interaction tests
- Storybook documentation

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
