# Appendix 13: Design Token Proposal Template

Reusable reference for project delivery, reviews and engineering governance.

- Problem and repeated visual decision
- Semantic token name
- Light and dark values
- Accessibility impact
- Affected components
- Migration plan
- Design approval
- Documentation and visual test update

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
