# Appendix 2: Pull Request Template

Reusable reference for project delivery, reviews and engineering governance.

- Linked requirement and acceptance criteria
- Scope and architectural impact
- Screenshots or recordings for UI changes
- Testing evidence
- Accessibility verification
- Security and privacy impact
- Bundle or performance impact
- Deployment and rollback notes

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
