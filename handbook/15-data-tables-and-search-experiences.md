# 15. Data Tables and Search Experiences

Design dense enterprise interfaces without sacrificing usability or performance.

## Table standards

- Sticky headers, deliberate column widths, tooltips for truncation, accessible sort state, and full-width responsive behaviour.
- Use server pagination for large datasets and virtualization when rendering large visible sets.
- Keep actions predictable and confirm destructive operations.

## Search standards

Debounce user-driven requests, cancel stale queries, sync filters to the URL, preserve back-navigation state, and define empty versus no-result states.
