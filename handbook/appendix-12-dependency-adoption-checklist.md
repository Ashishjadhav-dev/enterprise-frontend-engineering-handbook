# Appendix 12: Dependency Adoption Checklist

Reusable reference for project delivery, reviews and engineering governance.

- Clear business or engineering need
- Bundle and runtime cost measured
- Maintenance activity reviewed
- Security posture reviewed
- Licence compatible
- SSR and browser compatibility verified
- Alternative native capability considered
- Removal strategy documented

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
