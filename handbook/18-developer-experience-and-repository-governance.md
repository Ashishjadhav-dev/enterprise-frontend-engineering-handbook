# 18. Developer Experience and Repository Governance

Make the correct workflow discoverable and fast.

## Repository essentials

- README, architecture decisions, feature READMEs, environment catalogue, UI standards, API standards, testing handbook, and release runbook.
- CODEOWNERS for auth, shared UI, API foundations, and major domains.
- Consistent scripts: dev, build, lint, lint:fix, typecheck, test, test:e2e, analyze, validate.

## Pull request expectations

- Small reviewable scope, linked requirement, screenshots for UI changes, test evidence, accessibility notes, performance impact, migration or rollback plan.
