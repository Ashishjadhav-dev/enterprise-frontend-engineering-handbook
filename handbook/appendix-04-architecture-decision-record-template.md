# Appendix 4: Architecture Decision Record Template

Reusable reference for project delivery, reviews and engineering governance.

- Status and date
- Context and problem statement
- Decision drivers
- Considered options
- Selected decision
- Positive and negative consequences
- Migration plan
- Owner and review date

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
