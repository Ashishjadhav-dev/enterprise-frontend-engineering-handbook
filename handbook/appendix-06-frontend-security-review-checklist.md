# Appendix 6: Frontend Security Review Checklist

Reusable reference for project delivery, reviews and engineering governance.

- No secrets in client bundle
- Authorization enforced server-side
- External input validated
- HTML sanitized
- Uploads validated
- Safe redirects
- CSP compatibility
- Sensitive data masked from logs

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
