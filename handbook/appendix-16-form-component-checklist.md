# Appendix 16: Form Component Checklist

Reusable reference for project delivery, reviews and engineering governance.

- Labels and descriptions
- Required and disabled states
- Field and summary errors
- Server validation
- Input preservation after failure
- Submission loading state
- Keyboard order
- Analytics only where justified

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
