# 16. Observability and Operational Reliability

Make frontend failures traceable to releases, requests, routes, and user impact.

## Required signals

- Centralized error tracking with source maps and release versions.
- Core Web Vitals by browser, geography, route, and account segment.
- Correlation IDs propagated across frontend and backend.
- Structured audit events for sensitive actions.
- Feature flags with owners, expiry dates, and kill switches.

## Operational dashboards

JavaScript error rate, API error rate, slow endpoints, failed deployments, route performance, and critical flow conversion.
