# Appendix 22: Release Runbook Template

Reusable reference for project delivery, reviews and engineering governance.

- Release scope
- Database or contract dependencies
- Feature flags
- Pre-deployment checks
- Deployment steps
- Smoke tests
- Monitoring window
- Rollback trigger and owner

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
