# Appendix 9: Testing Plan Template

Reusable reference for project delivery, reviews and engineering governance.

- Business risks ranked
- Unit targets identified
- Component states covered
- Integration boundaries mocked responsibly
- Critical E2E journeys defined
- Accessibility checks included
- Fixtures and test data owned
- Flakiness response documented

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
