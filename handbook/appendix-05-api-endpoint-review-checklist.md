# Appendix 5: API Endpoint Review Checklist

Reusable reference for project delivery, reviews and engineering governance.

- Typed request and response
- Runtime validation at trust boundary
- Normalized errors
- Cancellation and timeout
- Retry policy
- Idempotency for critical mutation
- Cache and invalidation plan
- Correlation ID and monitoring

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
