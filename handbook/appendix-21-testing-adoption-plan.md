# Appendix 21: Testing Adoption Plan

Reusable reference for project delivery, reviews and engineering governance.

- Start with auth and one critical journey
- Add unit coverage for business rules
- Build reusable MSW handlers
- Create stable fixtures
- Run critical Playwright flows in CI
- Add accessibility smoke checks
- Track flakes as defects
- Expand changed-code coverage

## Usage

Copy this checklist into an issue, pull request, architecture review, or team runbook. Add an owner and evidence for every completed item.
