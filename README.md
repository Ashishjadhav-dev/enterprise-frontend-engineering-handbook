# Enterprise Frontend Engineering Handbook

A practical, vendor-neutral guide for designing scalable, secure, performant and maintainable Next.js applications.

## What this demonstrates

- Feature-oriented frontend architecture
- Server-first Next.js design
- Design systems and global CSS tokens
- Type-safe API and repository patterns
- Authentication and frontend security
- State ownership and data caching
- Performance budgets and optimisation
- Testing, accessibility and CI/CD
- Observability, governance and legacy modernisation
